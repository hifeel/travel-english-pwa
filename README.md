# 여행 영어 대화 모음 (PWA)

매일 아침 여행 영어 대화 60개(2026-09-28 ~ 2026-11-26)를 모아 검색·분류·음성 듣기·오프라인 학습이 가능하게 만든 정적 PWA입니다.

## 기능
- 최신순 장면 카드 목록 + 키워드 검색 + 카테고리/학습 상태 필터
- 말풍선 대화 화면 (`You` vs `Staff`), 전체/개별 한국어 뜻 토글
- 브라우저 음성 합성(`speechSynthesis`)을 통한 문장별·전체 영어 듣기
- 핵심 표현 카드 & 따라 말해 보기 문장 하이라이트
- 학습 완료(`studied`) / 즐겨찾기(`favorite`) 로컬 저장 (`localStorage`)
- 오프라인 캐시 (`sw.js`) 및 홈 화면 설치 (`manifest.webmanifest`)
